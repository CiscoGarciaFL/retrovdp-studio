# RetroVDP Studio v0.1.0-beta.13

This feature prerelease completes the current Supported Targets catalog with
native static-asset workflows for Atari Lynx and Neo Geo object processors,
four display-adapter families, and two character-display families. It
supersedes `v0.1.0-beta.12` and keeps the same RetroVDP Studio application,
settings, package, and recipe identities.

## Object-processor target support

- Added Atari Lynx object-scene conversion with 4bpp packed pixels, a native
  linked SCB list, pen palettes, scaling state, collision metadata, and raw
  `.SPR`, `.SCB`, `.PAL`, and `.REG` output.
- Added Neo Geo FIX-layer and chained-sprite conversion with native 4bpp tile
  data, FIX maps or object lists, 16-bit palette output, chaining, flip,
  priority, palette-bank, and shrink controls.
- Added hardware-aware Character and Sprite editor limits and native editor
  export for both object processors.

## Display-adapter target support

- Added Amstrad CPC Mode 0, Mode 1, and Mode 2 conversion with native pixel
  packing, 16 KiB eight-line screen-memory interleave, and ink/border state.
- Added IBM CGA 40-column and 80-column text buffers plus 320×200 and 640×200
  graphics with native even/odd scanline banks and color-select state.
- Added IBM EGA text plus planar 320×200 and 640×350 16-color graphics,
  including four-plane framebuffer and palette-register output.
- Added Apple IIe text, lo-res, hi-res, and double-hi-res page conversion with
  sparse Apple memory addressing and aux/main double-hi-res banks.

## Character-display target support

- Added Timex Sinclair 1000 / ZX81-class 32×24 text and 64×48 block-graphics
  conversion to complete 793-byte, HALT-delimited display files.
- Added TRS-80 Model I/III 64×16 text and native 128×48 2×3 semigraphics
  conversion to 1 KiB display RAM.
- Added native character-pattern and screen-map export for all six new display
  targets, with `.CHR`, `.VRAM`, `.PAGE`, `.DFILE`, `.PAL`, and `.REG` assets
  selected according to the active hardware.

## Application integration and quality

- All 20 catalog targets are now implemented and selectable in new projects
  and Project Settings, with 57 registered conversion modes across the full
  target set.
- Added project persistence, target-aware previews, palette handling, CLI
  conversion, raw export naming, capability summaries, and documentation for
  the new targets.
- Targets without hardware sprites expose Screen Image and Character
  workspaces without advertising a native Sprite workspace.
- Corrected enhanced-sprite recipe loading so saved F18A 3-bit pixel values
  survive a project round trip.
- Extended core, export, interface, project, and CLI validation to cover the
  completed catalog and native memory-region contracts.

## Downloads and installation

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer: use the AppImage, or the Debian package on
  Ubuntu 22.04 and compatible systems.
- Linux ARM64/AArch64 with glibc 2.38 or newer: use the `aarch64` AppImage, or
  the `arm64` Debian package on Ubuntu 24.04 and compatible systems.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages contain their required Qt runtime. Qt, CMake, and a compiler are
not required to run them. Linux systems must provide their normal graphics and
window-system libraries, including the OpenGL and EGL dispatch runtimes.

For an AppImage, mark the downloaded file executable before launching it:

```shell
chmod +x RetroVDPStudio-0.1.0-beta.13-Linux-x86_64.AppImage
./RetroVDPStudio-0.1.0-beta.13-Linux-x86_64.AppImage
```

Use the corresponding `aarch64` filename on Linux ARM64.

For a warning-free local Debian installation on x64:

```shell
install -m 0644 ./retrovdp-studio_0.1.0-beta.13_amd64.deb /tmp/retrovdp.deb
sudo apt install /tmp/retrovdp.deb
rm /tmp/retrovdp.deb
```

Use the `arm64` package filename for Ubuntu 24.04 ARM64. An `_apt`
unsandboxed-download notice for a package stored beneath a private home
directory is harmless when installation otherwise completes. Do not weaken
home-directory or APT permissions. The bundled runtime remains isolated under
`/opt/retrovdp-studio`.

If KDE Plasma retains a generic application icon after installation, log out
and back in or run `kbuildsycoca5 --noincremental` on Plasma 5 or
`kbuildsycoca6 --noincremental` on Plasma 6 as the current user.

## Upgrade, signing, and known limitations

Beta.13 is an in-place settings and recipe upgrade from beta.12. Installed
Windows, macOS, and Debian copies keep the same frozen application identity;
portable ZIP and AppImage users replace the previous artifact manually.

These beta packages are preview software and are not signed with a publicly
trusted Windows or Apple Developer ID certificate; the macOS bundle uses an
ad-hoc signature. Verify the filename and SHA-256 digest before accepting a
platform trust prompt.

- Windows may show Microsoft Defender SmartScreen's **Windows protected your
  PC** prompt. After verifying the checksum, choose **More info** and **Run
  anyway** for this specific download.
- macOS may report that the developer cannot be verified. After verifying the
  checksum, Control-click the application and choose **Open**, or authorize
  this specific application in **System Settings → Privacy & Security**.
- The application produces native static graphics assets; it is not a complete
  emulator of scanline timing, composite-video artifact color, collision
  behavior, or software sprite engines on hardware without native sprites.
- FFmpeg and FFprobe are optional external tools and are not bundled. Video
  clip extraction and media probing require them to be installed or configured
  in Preferences.
- CLI conversion remains limited to Screen Image recipes. Update discovery and
  automatic installation are not included.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/retrovdp-studio/issues> with the artifact
name, operating-system version, selected target/mode, and relevant diagnostics.
