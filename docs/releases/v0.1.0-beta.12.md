# RetroVDP Studio v0.1.0-beta.12

This corrective prerelease fixes the Active Target dropdown introduced in
`v0.1.0-beta.11`. It supersedes beta.11 and retains the same application,
settings, package, and recipe identities.

## Active Target hotfix

- The Project Bar now displays the active target immediately after startup.
- The dropdown explicitly reacts when its model becomes available, preventing
  a valid active target such as the TMS9918A from being represented by a blank
  selection.
- The Supported Targets catalog and Project Bar remain synchronized after
  project-target configuration changes.
- Interface coverage now verifies both the active target value and the label
  visible to the user.

Beta.12 otherwise contains the complete beta.11 feature set, including the
Nintendo Game Boy, Game Boy Color, and Super NES PPU workflows; hardware-native
exports; and the bundled offline Supported Targets catalog.

## Downloads and installation

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer: use the AppImage, or the Debian package on
  Ubuntu 22.04 and compatible systems.
- Linux ARM64/AArch64 with glibc 2.38 or newer: use the `aarch64` AppImage, or
  the `arm64` Debian package on Ubuntu 24.04 and compatible systems.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages contain their required Qt runtime. Qt, CMake, and a compiler are
not required to run them. Linux systems must provide their normal graphics and
window-system libraries, including the OpenGL and EGL dispatch runtimes.

For an AppImage, mark the downloaded file executable before launching it:

```shell
chmod +x RetroVDPStudio-0.1.0-beta.12-Linux-x86_64.AppImage
./RetroVDPStudio-0.1.0-beta.12-Linux-x86_64.AppImage
```

Use the corresponding `aarch64` filename on Linux ARM64.

For a warning-free local Debian installation on x64:

```shell
install -m 0644 ./retrovdp-studio_0.1.0-beta.12_amd64.deb /tmp/retrovdp.deb
sudo apt install /tmp/retrovdp.deb
rm /tmp/retrovdp.deb
```

Use the `arm64` package filename for Ubuntu 24.04 ARM64. An `_apt`
unsandboxed-download notice for a package stored beneath a private home
directory is harmless when installation otherwise completes. Do not weaken
home-directory or APT permissions. The bundled runtime remains isolated under
`/opt/retrovdp-studio`.

If KDE Plasma retains a generic application icon after installation, log out
and back in or run `kbuildsycoca5 --noincremental` on Plasma 5 or
`kbuildsycoca6 --noincremental` on Plasma 6 as the current user.

## Upgrade, signing, and known limitations

Beta.12 is an in-place settings and recipe upgrade from beta.11. Installed
Windows, macOS, and Debian copies keep the same frozen application identity;
portable ZIP and AppImage users replace the previous artifact manually.

These beta packages are preview software and are not signed with a publicly
trusted Windows or Apple Developer ID certificate; the macOS bundle uses an
ad-hoc signature. Verify the filename and SHA-256 digest before accepting a
platform trust prompt.

- Windows may show Microsoft Defender SmartScreen's **Windows protected your
  PC** prompt. After verifying the checksum, choose **More info** and **Run
  anyway** for this specific download.
- macOS may report that the developer cannot be verified. After verifying the
  checksum, Control-click the application and choose **Open**, or authorize
  this specific application in **System Settings → Privacy & Security**.
- Game Boy window placement, additional Super NES layers, color math, windows,
  HDMA, raster effects, runtime sprite evaluation, collision behavior, and
  full PPU emulation remain outside this static-asset release.
- FFmpeg and FFprobe are optional external tools and are not bundled. Video
  clip extraction and media probing require them to be installed or configured
  in Preferences.
- CLI conversion remains limited to Screen Image recipes. Update discovery and
  automatic installation are not included.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/retrovdp-studio/issues> with the artifact
name, operating-system version, selected target/mode, and relevant diagnostics.
