# RetroVDP Studio v0.1.0-beta.8

This feature prerelease brings the outstanding target, media, and platform
work together: native HuC6270, VIC-II, and VIC-20 conversion; video clip
extraction, monitoring, mapping, and parallel frame conversion; and native
Linux ARM64 distribution. It supersedes `v0.1.0-beta.6` and keeps the same
RetroVDP Studio application, settings, package, and recipe identities.

The `v0.1.0-beta.7` tag did not publish a GitHub Release because its ARM64 job
attempted to run Qt's Ubuntu 24.04 ARM64 binaries on Ubuntu 22.04. Beta.8 moves
the ARM64 build and package baseline to Ubuntu 24.04 and retains an independent
clean package-verification job.

## New target support

- Added NEC/Hudson HuC6270 background conversion at 256×224 and 320×224 with
  4-plane tiles, BAT entries, sixteen background palettes in the complete VCE
  table, VDC/VCE state, Character editing, and compound Sprite editing.
- Added MOS VIC-II high-resolution and multicolor character and bitmap modes,
  including native character/bitmap, screen, color-RAM, and register output;
  Character editing; and native 24×21 Sprite editing.
- Added MOS VIC/VIC-20 high-resolution and multicolor character modes at their
  native geometry, including character, screen, color-memory, and register
  output. VIC-20 intentionally exposes no sprite workspace because the
  original VIC has no hardware sprites.
- Includes the Yamaha V9938/V9958, Sega Master System, and Sega Genesis/Mega
  Drive target, editor, and export expansion introduced after beta.6.

## Media and application workflow

- Added FFmpeg/FFprobe discovery, media probing, bounded frame and audio
  extraction, timestamped clip packages, source and output monitors, and
  recipe-driven conversion of every extracted frame.
- Added deterministic bounded parallel conversion workers and native JSON,
  CSV/TSV, and Daphne/Hypseus clip-map interchange, with Unity and Godot 4
  reference loaders.
- Project Settings enables HuC6270, VIC-II, and VIC-20 alongside the previously
  implemented targets, while planned targets remain visible but disabled.
- RAW HuC6270 exports use `.TILES`, `.BAT`, `.PAL`, and `.REG`; Commodore
  exports use `.CHR` or `.BITMAP`, `.SCR`, optional `.COL`, and `.REG`.
- Target profiles, display modes, editor capabilities, project target choices,
  and version-1 recipe persistence share the validated target registry.

## Linux ARM64 correction

- ARM64 builds and packages now run natively on Ubuntu 24.04, matching the
  runtime baseline of the official Qt ARM64 binaries.
- A separate clean Ubuntu 24.04 ARM64 job downloads the completed AppImage and
  Debian artifacts, audits every ELF machine type, launches both packages,
  validates the CLI version, removes the Debian package, and checks cleanup.
- Linux x86_64 remains built on Ubuntu 22.04 with a glibc 2.34 floor. Linux
  ARM64 requires glibc 2.38 or newer and is package-tested on Ubuntu 24.04.

## Downloads

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer: use the AppImage, or the Debian package on
  Ubuntu 22.04 and compatible systems.
- Linux ARM64/AArch64 with glibc 2.38 or newer: use the `aarch64` AppImage, or
  the `arm64` Debian package on Ubuntu 24.04 and compatible systems.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages contain their required Qt runtime. Qt, CMake, and a compiler are
not required to run them.

## Upgrade and known limitations

Beta.8 is an in-place settings and recipe upgrade from beta.6. Installed
Windows, macOS, and Debian copies keep the same frozen application identity;
portable ZIP and AppImage users replace the previous artifact manually.

These beta packages are not signed with a publicly trusted Windows or Apple
Developer ID certificate; the macOS bundle uses an ad-hoc signature. Verify
the filename and SHA-256 digest before accepting a platform trust prompt.

- FFmpeg and FFprobe are optional external tools and are not bundled. Video
  clip extraction and media probing require them to be installed or configured
  in Preferences.
- The monitor displays audio metadata but does not yet play synchronized
  audio. Loose VOB ordering, authored DVD navigation, and execution of
  per-entry mapping recipes remain deferred.
- Native structured-editor map, sprite-pattern, and linked-SAT export remains
  part of the shared editor/export milestone. CLI conversion remains limited
  to Screen Image recipes.
- Update discovery and automatic installation are not included.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/retrovdp-studio/issues> with the artifact
name, operating-system version, selected target/mode, and relevant diagnostics.
