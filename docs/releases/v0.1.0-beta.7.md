# RetroVDP Studio v0.1.0-beta.7

This intentional feature prerelease adds native Linux ARM64 distribution to
the multi-VDP feature set introduced in beta.6. It supersedes
`v0.1.0-beta.6` and keeps the same RetroVDP Studio application, settings,
package, and recipe identities.

Linux ARM64 packages are built natively on Ubuntu 22.04 ARM64 and then
install-tested and smoke-tested again on Ubuntu 24.04 ARM64. The workflow also
audits every packaged ELF file so x86-64 and AArch64 files cannot be mixed.

## New target support

- Added native Yamaha V9938 SCREEN 5–8 conversion and V9958 SCREEN 10–12
  YJK/YAE conversion, including native geometry, palette encoding, target
  memory, previews, exports, and live-update behavior.
- Added Sega Master System Mode 4 at 256×192, 256×224, and PAL 256×240 with
  planar 4bpp tiles, name-table attributes, two RGB222 CRAM banks, registers,
  native Character editing, and 8×8/8×16 Sprite editing.
- Added Sega Genesis/Mega Drive non-interlaced Mode V at H32 256×224, H40
  320×224, PAL H32 256×240, and PAL H40 320×240. Screen Image output contains
  packed 4bpp tiles, a big-endian Plane A map, four RGB333 CRAM banks, and VDP
  registers.
- Added Genesis Character editing for 2,048 packed 4bpp 8×8 tiles with four
  palette banks and mode-derived 32/40-column maps.
- Added Genesis Sprite editing for the active 64-entry H32 or 80-entry H40
  limit, four palette banks, and every rectangular width/height combination
  from 8 through 32 pixels in 8-pixel steps.

## Application and workflow changes

- Target profiles and display modes now carry stable IDs, native geometry,
  palette, memory, character, and sprite capabilities through a validated
  registry shared by the GUI and CLI.
- Screen Image conversion and live update now follow the selected target's
  resolution, color depth, palette, and converter instead of retaining
  TMS9918A assumptions.
- Project Settings enables every implemented target and leaves planned targets
  visible but disabled with their roadmap status.
- Character and Sprite project data, palette banks, target selections, and
  rectangular Genesis sprite geometry persist in version-1 recipes.
- RAW Sega exports use `.TILES`, `.MAP`, `.PAL`, and `.REG` asset names.
- The splash screen and About dialog read the version generated from the single
  `RETROVDP_VERSION` declaration used by the CLI and packages.
- The Windows preview scripts configure a missing build directory before
  building and can be launched with a process-scoped PowerShell execution-policy
  bypass when local policy blocks unsigned development scripts.
- Added native Linux ARM64 CI, AArch64 AppImage and `arm64` Debian packaging,
  ELF architecture audits, and package smoke tests on Ubuntu 22.04 and 24.04
  ARM64 runners.

## Deliberate target boundaries

- Genesis Screen Image conversion emits one opaque Scroll A plane. Scroll B,
  Window, priority composition, and interlaced Mode 2 require separate authored
  data and are not inferred from a flat source image.
- Character and Sprite workspaces preserve native target data in projects, but
  native structured-editor map, sprite-pattern, and SAT export is still part of
  the shared editor/export milestone. CLI conversion remains limited to Screen
  Image recipes.

## Downloads

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer: use the AppImage, or the Debian package on
  Ubuntu 22.04 and compatible systems.
- Linux ARM64/AArch64 with glibc 2.34 or newer: use the `aarch64` AppImage, or
  the `arm64` Debian package on Ubuntu 22.04 and compatible systems.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages contain their required Qt runtime. Qt, CMake, and a compiler are
not required to run them.

## Upgrade and Debian installation

Beta.7 is an in-place settings and recipe upgrade from beta.6. Installed
Windows, macOS, and Debian copies keep the same frozen application identity;
portable ZIP and AppImage users replace the previous artifact manually.

For a warning-free local Debian installation:

```shell
install -m 0644 ./retrovdp-studio_0.1.0-beta.7_amd64.deb /tmp/retrovdp.deb
sudo apt install /tmp/retrovdp.deb
rm /tmp/retrovdp.deb
```

On an ARM64 Debian/Ubuntu system, use
`retrovdp-studio_0.1.0-beta.7_arm64.deb` in the same commands.

An `_apt` unsandboxed-download notice for a package stored beneath a private
home directory is harmless when installation otherwise completes. Do not
weaken home-directory or APT permissions. The application runtime remains
isolated under `/opt/retrovdp-studio`; the package does not install global Qt
configuration, plugin, or QML paths.

If KDE Plasma retains a generic application icon after installation, log out
and back in or run `kbuildsycoca5 --noincremental` on Plasma 5 or
`kbuildsycoca6 --noincremental` on Plasma 6 as the current user.

## Preview signing and known limitations

These beta packages are not signed with a publicly trusted Windows or Apple
Developer ID certificate; the macOS bundle uses an ad-hoc signature. Verify
the filename and SHA-256 digest before accepting a platform trust prompt.

- Update discovery and automatic installation are not included.
- Linux support targets x86_64 and ARM64 systems with glibc 2.34 or newer.
  Native ARM64 package tests cover Ubuntu 22.04 and 24.04. X11 is covered by
  automation; other Wayland distributions and compositors remain preview
  environments.
- Structured Character and Sprite hardware export remains deferred as described
  above.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/retrovdp-studio/issues> with the artifact
name, operating-system version, selected target/mode, and relevant diagnostics.
