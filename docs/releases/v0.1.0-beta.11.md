# RetroVDP Studio v0.1.0-beta.11

This feature prerelease adds complete static-asset workflows for the Nintendo
Game Boy, Game Boy Color, and Super NES PPUs, and introduces an offline
Supported Targets catalog with real consumer-product photographs. It
supersedes `v0.1.0-beta.10` and keeps the same RetroVDP Studio application,
settings, package, and recipe identities.

## Nintendo PPU target support

- Added Game Boy 160×144 background conversion with 2bpp tiles, a 32×32 map,
  BGP/OBJ palette registers, LCD state, 384-tile Character editing, and
  40-entry OAM Sprite editing.
- Added Game Boy Color 160×144 background conversion with two VRAM banks,
  map attributes, eight RGB555 background and object palettes, 768-tile
  Character editing, and color OAM authoring.
- Added Super NES Mode 0, Mode 1, and Mode 3 BG1 conversion at 256×224 with
  2bpp, 4bpp, and 8bpp planar tiles, 16-bit maps, CGRAM, PPU state, 1,024
  authored Character patterns, and 128-entry OAM Sprite editing.
- Added native Nintendo editor export for character, map, attribute, palette
  or CGRAM, sprite, OAM, and register assets, including map-range, VRAM-layout,
  sprite-size-pair, and OAM-address validation.
- Added target-aware Game Boy scanline limits, global 8×8/8×16 object sizing,
  Super NES small/large object pairs, palette banks, flips, priority, and
  transparent color-zero behavior.
- Added RAW Screen Image output using `.TILES`, `.MAP`, optional `.ATTR`,
  `.PAL` or `.CGRAM`, and `.REG` files.

## Supported Targets catalog

- Added **Help → About Supported Targets**, a categorized catalog covering all
  12 implemented targets and eight planned or research targets.
- Bundled the catalog data and real consumer-product thumbnails in the
  application so summaries and images load immediately without Internet
  access. Source pages remain optional attribution and read-more links and are
  not checked automatically.
- Added VDP, PPU, object-processor, display-adapter, and character-display
  category bars plus standardized hardware, capability, status, source, and
  licensing information.
- Project-selected targets use a stable blue panel that does not change when
  application focus changes. The active target alone receives a white outline.
- A new project always activates one of its selected targets, the Project Bar
  always shows a valid active selection, and Project Settings prevents the
  final selected target from being unchecked.

## Application and development workflow

- Corrected Super Famicom and Super NES image ordering and added a TurboGrafx
  console photograph alongside the PC Engine example.
- Made relocated Windows preview trees detect and refresh stale CMake caches,
  avoiding source-directory mismatch failures after moving or cloning the
  repository.
- Extended target metadata, project persistence, command-line target names,
  validation coverage, and hardware-native export naming for the Nintendo
  profiles.

## Downloads and installation

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer: use the AppImage, or the Debian package on
  Ubuntu 22.04 and compatible systems.
- Linux ARM64/AArch64 with glibc 2.38 or newer: use the `aarch64` AppImage, or
  the `arm64` Debian package on Ubuntu 24.04 and compatible systems.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages contain their required Qt runtime. Qt, CMake, and a compiler are
not required to run them. Linux systems must provide their normal graphics and
window-system libraries, including the OpenGL and EGL dispatch runtimes.

For an AppImage, mark the downloaded file executable before launching it:

```shell
chmod +x RetroVDPStudio-0.1.0-beta.11-Linux-x86_64.AppImage
./RetroVDPStudio-0.1.0-beta.11-Linux-x86_64.AppImage
```

Use the corresponding `aarch64` filename on Linux ARM64.

For a warning-free local Debian installation on x64:

```shell
install -m 0644 ./retrovdp-studio_0.1.0-beta.11_amd64.deb /tmp/retrovdp.deb
sudo apt install /tmp/retrovdp.deb
rm /tmp/retrovdp.deb
```

Use the `arm64` package filename for Ubuntu 24.04 ARM64. An `_apt`
unsandboxed-download notice for a package stored beneath a private home
directory is harmless when installation otherwise completes. Do not weaken
home-directory or APT permissions. The application runtime remains isolated
under `/opt/retrovdp-studio`; the package does not install global Qt
configuration, plugin, or QML paths.

If KDE Plasma retains a generic application icon after installation, log out
and back in or run `kbuildsycoca5 --noincremental` on Plasma 5 or
`kbuildsycoca6 --noincremental` on Plasma 6 as the current user.

## Upgrade, signing, and known limitations

Beta.11 is an in-place settings and recipe upgrade from beta.10. Installed
Windows, macOS, and Debian copies keep the same frozen application identity;
portable ZIP and AppImage users replace the previous artifact manually.

These beta packages are preview software and are not signed with a publicly
trusted Windows or Apple Developer ID certificate; the macOS bundle uses an
ad-hoc signature. Unsigned packages do not provide the publisher identity or
tamper assurance of a future signed release. Verify the filename and SHA-256
digest before accepting a platform trust prompt.

- Windows may show Microsoft Defender SmartScreen's **Windows protected your
  PC** prompt. After verifying the checksum, choose **More info** and **Run
  anyway** for this specific download.
- macOS may report that the developer cannot be verified. After verifying the
  checksum, Control-click the application and choose **Open**, or authorize
  this specific application in **System Settings → Privacy & Security**.
- Game Boy window placement, additional Super NES layers, color math, windows,
  HDMA, raster effects, runtime sprite evaluation, collision behavior, and
  full PPU emulation are outside this static-asset release.
- FFmpeg and FFprobe are optional external tools and are not bundled. Video
  clip extraction and media probing require them to be installed or configured
  in Preferences.
- The monitor displays audio metadata but does not yet play synchronized
  audio. Loose VOB ordering, authored DVD navigation, and execution of
  per-entry mapping recipes remain deferred.
- CLI conversion remains limited to Screen Image recipes. Update discovery and
  automatic installation are not included.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/retrovdp-studio/issues> with the artifact
name, operating-system version, selected target/mode, and relevant diagnostics.
